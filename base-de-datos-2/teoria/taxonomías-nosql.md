Las 5 taxonomías principales de bases de datos NoSQL son:

1. **Clave-Valor:** Almacenan datos como un diccionario simple, donde una clave única permite acceder rápidamente a su valor asociado. Ejemplo: **Redis** o Riak.
2. **Orientadas a Documentos:** Guardan la información en documentos flexibles, jerárquicos y autodescriptivos (como JSON o BSON). Ejemplo: **MongoDB** o CouchDB.
3. **Orientadas a Familias de Columnas (Wide-column):** Organizan los datos agrupándolos en columnas flexibles dentro de particiones, lo que permite una escalabilidad masiva. Ejemplo: **Cassandra** o HBase.
4. **Orientadas a Grafos:** Optimizadas específicamente para almacenar entidades (nodos) y navegar por sus complejas relaciones (aristas) de forma muy rápida. Ejemplo: **Neo4j** o FlockDB.
5. **Motores de Búsqueda:** Diseñadas para indexar grandes volúmenes de datos y realizar búsquedas eficientes de texto completo. Ejemplo: **Elasticsearch** o Solr.
