# Quotes

## Dominio

Una base de datos contiene información sobre empresas que cotizan en bolsa.
- De cada empresa conocemos su nombre, rubro, sede y si está activa.
- Cada empresa tiene un historial de cotizaciones de sus acciones.
- De cada cotización conocemos la fecha, el precio de apertura y el de cierre.
