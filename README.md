# 📚 Cuaderno de Estudio Académico (Vault de Obsidian)

## 🎯 Objetivo y Filosofía

Este repositorio es mi base de conocimiento personal (PKM) y cuaderno de trabajo digital, construido con **Obsidian**. Su propósito fundamental es el **estudio riguroso y la resolución detallada de ejercicios** de materias universitarias, con énfasis en la **claridad matemática** y la **progresión lógica** de los conceptos.

Cada nota está diseñada para ser un recurso de aprendizaje que cumple con dos principios clave:

1. **Rigor y Detalle:** Documentar cada paso en la resolución de problemas (especialmente en Álgebra Lineal y Matemática Discreta), asegurando que el proceso de razonamiento sea completamente transparente.
    
1. **Interconexión (Linking):** Utilizar la arquitectura de enlaces de Obsidian para conectar conceptos teóricos, ejercicios resueltos y temas relacionados, facilitando un repaso activo y un entendimiento profundo.

## 💻 Entorno Recomendado

### Plugins Esenciales

Las resoluciones matemáticas y los diagramas se apoyan en los siguientes plugins comunitarios:

- **Obsidian LaTeX Suite:** Necesario para la representación completa y la sintaxis avanzada de fórmulas matemáticas.
    
- **Obsidian Excalidraw:** Requerido para ver los archivos `.excalidraw.md` que contienen diagramas y bocetos conceptuales.
    

*(La configuración de estos plugins está incluida en la carpeta `.obsidian/`.)*
